## 新环境验收建议

先验证配置生成和路径，再启动基础服务。完成未授权拒绝、独立密钥范围、Mac 隧道重连与云端重启恢复检查后，用上述固定提交构建 Debug APK，校验下载结果。随后演练清理预览、过期清理和空间不足拒绝，最后再接入真实项目。

需要模拟器测试时，先把产物传到 Mac，并确认本地模拟器 MCP 的状态和所选 AVD；测试结果应单独记录，不能沿用本页的编译成功作为应用功能通过的证据。

## 公开提取版的本地检查

提取过程中额外修复了取消任务认领竞态，并为其补充隔离回归测试；原生产部署未在本次整理中升级。公开版目前在临时目录中运行8项编译/清理安全测试、7项配置与Mac启动配置测试，共15项全部通过。另有公开文件基础扫描及Python/Shell语法检查；这些检查不等于新主机部署或真实Mac应用端到端验证。

配置生成器只生成私有文件；Mac plist生成器只渲染配置，不会启动应用。仓库 CI 只跑无真实云凭据的 headless 检查。
